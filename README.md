## ⚙️ Getting Started

Follow these steps to run the projects locally:

**1. Clone the repository**

```bash
git clone https://github.com/rajisdevil/Web-Development-Projects.git
```

**2. Navigate to the project directory**

```bash
cd Web-Development-Projects
```

**3. Open the project**

Open the required project folder and launch its `index.html` file in your browser.

You can also use the Live Server extension in Visual Studio Code.
