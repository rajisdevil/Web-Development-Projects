## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rajisdevil/Python-Mini-Projects.git
   ```

2. Open the project folder:

   ```bash
   cd Python-Mini-Projects
   ```

3. Open `index.html` in your browser.

## 🌍 Deployment

This website can be hosted for free using GitHub Pages.

1. Open your GitHub repository.
2. Navigate to Settings.
3. Select Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Select `main` as the branch.
6. Select `/ (root)` as the folder.
7. Click Save.

Your website will be published at:

https://rajisdevil.github.io/Python-Mini-Projects/
